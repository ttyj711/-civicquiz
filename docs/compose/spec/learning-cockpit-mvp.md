# 学习闭环 MVP 信息架构（可交互原型）

## Report

**What was built** — 在仓库根目录交付可交互 HTML 原型（`index.html` + `styles.css` + `app.js`），以手机画框呈现 CivicQuiz 学习闭环 MVP：四 Tab（首页学习驾驶舱 / 刷题 / 考试 / 我的备考驾驶舱），覆盖刷题即时反馈、考试倒计时与统一判分、错题收藏闭环、历史考试复盘、设置内双主题。练习与考试交互已区分（练习即时解析；考试不显答案、支持答题卡与上一题/下一题）。

**Verification** — `node --check app.js` PASS；Playwright 无头冒烟（file://）全部 PASS：home、exam next/prev、exam favorite、exam submit、retake params、review content、resume exam、practice next gated、submit lifecycle blocks quiz reopen。控制台错误：无。

**Journey log**

- 续考入口曾 `go(exam-quiz)` 却不重建会话，落到空态——改为 `resume-exam` 显式重建。

- 无头冒烟会因子页隐藏 Tab 而误判，需从「返回首页」再进主 Tab。

## [S1] Problem

当前产品具备「个人中心 + 刷题答题」基本闭环，但更像题库工具而非备考助手：

1. 「我的」缺少「下一步做什么」引导，用户不知道该继续刷题还是复习错题。
2. 累计正确率、平均分等结果数据无行动建议，表达不直观。
3. 错题本、收藏夹、累计答题、考试次数并列展示，未体现学习优先级。
4. 历史考试只有时间与分数，缺少正确率、用时、错题入口，无法形成复习闭环。
5. 答题页进度感知弱、选项状态不完整、无即时反馈，练习与考试交互未区分。
6. 首页偏题库入口，未承担「今天学什么」的驾驶舱职责。

目标链路：**学习目标 → 刷题 → 即时反馈 → 错题复习 → 模拟考试 → 学习数据**。

### 信息架构（MVP）

```
首页（学习驾驶舱）
  今日任务 / 继续学习 / 今日建议 / 学习数据摘要
刷题
  题库列表 → 刷题设置（模式+题量）→ 练习中 → 练习结果
考试
  模拟考试列表 → 考试详情 → 考试中 → 考试结果 → 答卷回顾
我的（备考驾驶舱）
  今日进度 / 核心指标 / 今日建议 / 继续学习 / 历史考试 / 设置（外观）
```

### 首页

| 区块 | 行为 |
| --- | --- |
| 问候 + 昵称 | 时段问候、鼓励语 |
| 今日任务卡 | 今日进度条（完成/目标）、正确率、错题待巩固 |
| 继续学习 | 有进行中会话：展示进度并「继续答题」；无则推荐「随机练习 20 题」 |
| 今日建议 | 三条可行动入口：错题复习（N 道）/ 收藏题（N 道）/ 继续刷题 |
| 学习数据摘要 | 累计答题、正确率、考试次数 |

### 「我的」页

| 区块 | 行为 |
| --- | --- |
| 顶部 | 昵称 + 今日已完成 x/y 题 + 进度条 |
| 核心指标层 | 累计答题、正确率、错题（主层级） |
| 辅助指标层 | 收藏、模拟考试次数（次层级） |
| 今日建议 | 错题复习卡片（高优先级，「去复习」） |
| 继续学习 | 上次做到第 x/y 题，一键续做；无记录则引导开始练习 |
| 历史考试卡片 | 得分、正确率、题数、用时、「查看详情」 |
| 考试详情 | 得分/总分、正确率、对/错/未答、「查看错题」「再做一次」 |
| 设置 | 外观（舒缓绿/暖棕）移入设置，不再占据主区 |

### 答题页（练习模式 / 考试模式区分）

| 元素 | 规则 |
| --- | --- |
| 顶栏 | 「第 i / N 题」+ 题型标签 + 百分比 + 进度条 |
| 题干卡片 | 视觉中心；题干 17–18px 层级；收藏为题卡轻量操作（☆） |
| 选项四态 | 默认 ○ / 已选 ● / 答对 ✓ / 答错 ✕ |
| 练习模式 | 选择即判分；展示对错条、正确答案、解析、知识点；「下一题」 |
| 考试模式 | 只记答案不公布；「上一题 / 下一题」；最后一题「提交试卷」 |
| 主操作 | 未作答禁用「下一题」并提示「请选择答案」；已答可前进 |
| 答题卡 | 考试模式顶栏打开；题号网格（已答/未答/收藏）；「返回答题 / 交卷」 |
| 交卷后 | 清会话、结清进行中历史、不可回退重考，防重复计分 |

### 练习结果 / 考试结果

| 页 | 内容 |
| --- | --- |
| 练习结果 | 圆环正确数、一共/对/错/未答、考点小结（含掌握度星级）、答题卡 |
| 考试结果 | 大分数、正确率、对/错/未答；操作：查看错题 / 再做一次 / 返回首页 |
| 答卷回顾 | 逐题对错、我的答案 vs 正确答案、解析、上一题/下一题 |

### 交互状态

- 所有列表具备空态文案（鼓励式）。
- 练习答错自动进错题（未答不入错题本）；错题「去复习」进入错题练习。
- 多选需确认提交；单选/判断点选即判（练习）或即存（考试）。
- 倒计时 <5 分钟警示；到 0 自动交卷并打标。

### Mock 数据要求

- ≥1 个题库、≥8 道题（含单选/多选/判断）。
- 预置错题 ≥3、收藏 ≥2、历史考试 ≥2（含一条进行中）、今日进度部分完成。
- 历史考试 detail 非空，可走回顾/错题路径。

## [S3] Out of Scope

- 不改动 Taro 小程序 / Admin / Server 真实代码（本轮仅 HTML 原型）。
- 不做后端接口、登录、真实判分服务。
- 不做主观题、社交、付费、推送、多租户。
- 不做连续学习天数统计（提案中可选项）。
- 不追求像素级还原生产组件库，以信息架构与交互闭环为准。
